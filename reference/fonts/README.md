# Inter · archivos de referencia

Descargados el 28/10/2026 desde la respuesta a:
https://fonts.googleapis.com/css2?family=Inter:wght@200;400;500;600&display=swap

La respuesta original queda en `google-fonts-original.css`; los cuatro archivos TTF corresponden a pesos 200, 400, 500 y 600. Se incluye `OFL.txt`, obtenido de https://raw.githubusercontent.com/google/fonts/main/ofl/inter/OFL.txt.

Para autoalojar: copiar los TTF y la licencia a `dist/assets/fonts/`, crear reglas @font-face con rutas locales, y quitar del HTML la carga de fonts.googleapis.com. Esa modificación es opcional y no se aplicó a esta instantánea.
